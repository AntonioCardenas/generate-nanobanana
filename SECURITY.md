## Reporting a Vulnerability

We take the security of `generate-nanobanana` seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to the maintainer privately:
- By email to [INSERT CONTACT EMAIL HERE]
- Through GitHub Security Advisories, if enabled for this repository.

Please include the following information in your report:
*   Description of the vulnerability.
*   Steps to reproduce the vulnerability.
*   Possible impact of the vulnerability.
*   Any potential mitigation or fix you can suggest.

We will review the report and respond to you as soon as possible, usually within 48 hours. If the vulnerability is confirmed, we will work on a fix and coordinate a release date with you. We ask that you maintain confidentiality until the fix is released.

Thank you for helping keep this project secure!
